# Authored mining sound effects

현재 일반 돌 타격·보석 돌 타격·파괴·작동음은 [주 도구 전용 42개 WAV](tools/README.md)를 사용합니다. 아래 초기 공통 합성 자료 중 `ore_discovery.wav`는 여섯 도구의 보석 발견음으로 계속 공유합니다.

레이저·맥주·탐지기·분쇄기·엑스레이·정·기폭장치에는 [보조 도구 전용 합성 WAV 18개](auxiliary/README.md)를 추가했습니다. 동일한 48 kHz 스테레오 PCM 규격이며 구매·사용·거리 신호·파괴에 연결합니다.

일반 돌과 보석 효과음은 제공된 두 레퍼런스의 타격감·금속성 울림을 참고해 **처음부터 새로 합성한 소리**입니다. 원본에서 자른 구간이나 노이즈 제거 후 남은 파형을 사용하지 않습니다. 원본 음악·환경음·녹음 잡음이 포함될 경로가 없습니다.

## 초기 공통 합성 WAV

| 파일 | 용도 | 길이 | 피크 |
| --- | --- | ---: | ---: |
| `mining_hit_01.wav` | 일반 돌 타격 1 | 0.29초 | -6 dBFS |
| `mining_hit_02.wav` | 일반 돌 타격 2 | 0.32초 | -6 dBFS |
| `mining_hit_03.wav` | 일반 돌 타격 3 | 0.34초 | -6 dBFS |
| `mining_break.wav` | 일반 돌 파괴·작은 조각 낙하 | 0.72초 | -5 dBFS |
| `ore_hit_01.wav` | 보석 돌 타격 1 | 0.34초 | -6 dBFS |
| `ore_hit_02.wav` | 보석 돌 타격 2 | 0.36초 | -6 dBFS |
| `ore_hit_03.wav` | 보석 돌 타격 3 | 0.38초 | -6 dBFS |
| `ore_discovery.wav` | 보석 발견·즉시 획득 | 1.26초 | -5 dBFS |

모두 **48 kHz·16-bit PCM·스테레오·무압축·루프 없음**입니다. 시작은 0에서 부드럽게 올라가고 마지막 40 ms는 감쇠하며, 끝의 8 ms는 정확한 무음입니다. 별도의 잡음·배경 음악·리버브 녹음을 섞지 않습니다.

## 소리 구성

- 일반 돌: 짧고 낮은 접촉음, 여러 개의 빠르게 감쇠하는 공명, 곡괭이 날의 금속성 울림을 합쳤습니다. 파괴음에는 크기가 다른 조각이 연달아 떨어지는 작은 충격을 배치했습니다.
- 보석 돌: 돌의 접촉음 위에 금속·크리스털 공명을 배치했습니다. 가까운 주파수의 미세한 맥놀이와 배음으로 반짝임을 만들고, 잔향은 연속 채굴을 방해하지 않도록 짧게 감쇠합니다.
- 보석 발견: 즉시 나는 파괴 타격, 슬롯머신을 연상시키는 짧은 금속 타격의 연속, 마지막으로 넓게 울리는 밝은 소리로 구성했습니다. 배경 반주나 지속되는 음악은 없습니다.

레퍼런스 분석에서 일반 돌은 약 2.1 / 2.3 / 2.6 kHz의 울림과 짧은 접촉음, 보석은 약 2.3–3.1 kHz의 금속성 성분을 제작 기준으로 삼았습니다. 각 소리의 위상·음량 변화·타격 순서·감쇠는 합성 코드에서 새로 정합니다. 원본의 저음 반주나 파형·위상은 가져오지 않습니다.

합성 단계에서 접촉 피크를 부드럽게 누르고 음량을 맞춥니다. 스테레오는 같은 위상의 공명을 좌우에 조금씩 배치하므로 모노 스피커에서도 주요 소리가 상쇄되지 않습니다. 재생 코드는 기존처럼 타격 3종을 직전과 다르게 고르며, 등급·피해량에 따라 피치와 음량을 조금씩 바꿉니다. 발견음은 예약된 재생 채널을 사용해 후속 타격이 끊지 않게 합니다.

## 재생성

```powershell
python tools/audio/synthesize_mining_sounds.py
```

Python 표준 라이브러리만 사용하고 레퍼런스 파일은 필요하지 않습니다. `--group stone` 또는 `--group ore`로 한 묶음만 만들 수도 있습니다. 게임용 WAV와 함께 `artifacts/synthesized_mining_preview.wav`에 게임 재생 음량의 미리듣기를, `artifacts/synthesized_audio_report.json`에 순서·피크·무음 구간·PCM 해시를 저장합니다.

Godot는 완성된 WAV를 미리 불러옵니다. 타격·파괴 시 파일 읽기, 합성, 노이즈 제거, 재생 노드 생성은 없으며 기존의 고정된 14개 재생 채널을 재사용합니다. 현재 휘두르기·기계 작동음도 도구별 전용 WAV를 사용하고, 원석 재생성과 정산·경매 UI 소리는 기존 방식으로 합성합니다.

## 이전 편집 실험

보스 전용 등장·타격·파괴·능력·승리음 35개는 [bosses/README.md](bosses/README.md)에 별도로 기록했습니다. 이 음원도 원본 녹음이나 배경 음악을 섞지 않은 직접 합성 PCM입니다.

`prepare_mining_reference.py`와 `prepare_ore_reference.py`는 비교용으로 보존했습니다. 출력은 `artifacts/reference_edits`이며 게임용 합성 WAV를 덮어쓰지 않습니다. 이전 Ore 편집의 음악 억제는 완전한 음원 분리가 아니어서 반주가 일부 남았고, 현재 게임에서는 그 결과를 사용하지 않습니다.
