# 보스 전용 합성 음원

일곱 보스에 등장·타격·파괴·능력·승리 다섯 종류씩, 총 35개의 원본 WAV를 직접 합성했습니다. 레퍼런스 녹음, 음악, 샘플 라이브러리를 잘라 넣지 않았습니다.

| 파일 접두사 | 음색 기준 |
| --- | --- |
| `0_` | 낮은 돌 공명과 재생할 때의 아래로 떨어지는 울림 |
| `1_` | 무거운 돌 위에 금속 방패의 공명 |
| `2_` | 높은 얼음·유리성 공명과 약점 이동의 짧은 상승음 |
| `3_` | 시계 접점 같은 짧은 연속음과 금속 울림 |
| `4_` | 가시가 열리는 마찰성 접촉음과 날카로운 배음 |
| `5_` | 낮은 화산 타격·발사음과 돌 파편 접촉음 |
| `6_` | 높은 결정성 울림과 최종 승리의 상승 종결음 |

파일명은 `<번호>_entry / hit / break / ability / victory.wav`입니다. 길이는 각각 1.15 / 0.24 / 0.47 / 0.68 / 1.45초이며 **48 kHz · 스테레오 · PCM16 · 무압축 · 반복 없음**입니다. 합성 피크는 −4.8 dBFS로 맞추고 끝은 디지털 무음으로 감쇠합니다. 재생 시 고정된 8개 채널과 효과 재생 간격 제한을 사용합니다. 등장·승리는 별도 채널을 예약해 연속 타격이 끊지 않습니다.

```powershell
python tools/audio/synthesize_boss_sounds.py
```

Python 표준 라이브러리와 프로젝트의 기존 공명 합성 함수를 사용합니다. 이 명령은 WAV, Godot 임포트 설정, `scripts/boss_audio_bank.gd`, 측정값 `manifest.json`을 생성합니다. `artifacts/boss_sound_preview.wav`에는 보스 순서대로 다섯 효과음을 낮춘 음량으로 이어 붙입니다. 게임 중에는 합성·파일 로딩·재생 노드 생성 없이 미리 로드한 WAV를 재사용합니다.
