# 보조 도구 합성음

보조 도구 7종에 사용하는 효과음 18개입니다. 녹음 파일 없이 진동자·감쇠 공진·짧은 접촉음을 코드로 조합했습니다. 레퍼런스에서 자른 파형이나 배경 음악을 포함하지 않습니다.

| 도구 | 소리 구성 |
| --- | --- |
| 레이저 | 장치 준비음, 빠르게 내려가는 전자 발사음과 충격 |
| 맥주 | 잔의 짧은 울림, 연속해서 마시는 소리 |
| 탐지기 | 전원음, 거리에 따라 간격과 피치가 바뀌는 짧은 신호음 |
| 분쇄기 | 준비·가동, 회전 톱니의 반복 충격, 종료음 |
| 엑스레이 | 세 단계로 올라가는 스캔 신호 |
| 정 | 구매·등장, 세 번의 점점 높은 금속 타격, 마지막 파괴 |
| 기폭장치 | 준비음, 저음 충격과 흩어지는 파편 |

48 kHz·스테레오·16-bit PCM WAV, 무압축·루프 없음. 피크는 −4.5 dBFS(탐지 신호 −5.5 dBFS)이며 끝 8 ms는 정확한 무음입니다. 재생 시에는 별도 음량을 적용하고 다섯 개의 고정 채널을 재사용합니다. 채굴 중에는 파일 읽기·파형 합성·재생 노드 생성이 없습니다.

```powershell
python tools/audio/synthesize_aux_sounds.py
```

Python 표준 라이브러리만 필요합니다. 생성기는 동일한 PCM을 재현하고 Godot의 무압축 임포트 설정과 프리로드 목록도 만듭니다. [manifest.json](manifest.json)은 길이·피크·DC 오프셋·해시·무음 구간을 기록합니다. 모든 소리를 게임 기본 음량으로 순서대로 붙인 미리듣기는 `artifacts/auxiliary_sound_preview.wav`, 순서와 시작 시각은 `artifacts/auxiliary_sound_timeline.json`입니다.
