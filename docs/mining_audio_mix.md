# 채굴 효과음 중첩 제어

`scripts/mining_audio.gd`가 일반 원석과 보스의 타격·파괴음을 함께 관리한다.
기존에 합성한 도구별 PCM 파일을 그대로 재생하며, 타격 중 파일 로딩이나 음원 합성은 하지 않는다.

- 직접 공격 한 번의 모든 접촉은 `begin_impact()` / `end_impact()` 사이에 모은다.
  보석 발견 > 파괴 > 보석 타격 > 일반 타격 순으로 대표 소리 하나를 고른다.
- 공명·충격파의 피해 처리는 그대로 진행한다. 프레임별 연쇄음만 묶고, 120ms 간격과 -8dB 감쇠를 적용한다.
  직접 타격 직후 55ms와 보석 발견 직후 90ms에는 추가 연쇄음을 생략한다.
- 직접 타격은 32ms 간격으로 재생할 수 있다. 타격 잔향은 최대 3개, 연쇄음은 최대 1개이며
  새 직접 타격이 나오면 이전 잔향을 25ms에 걸쳐 -20dB까지 낮춘다.
- 보석 발견은 전용 재생 채널을 사용한다. 140ms 내 중복 발견음은 묶되 일반 보석 다음의
  특별 이상 보석은 우선할 수 있다. 발견 시 타격 잔향은 -24dB까지 낮춘다.
- `MiningSFX` 버스에는 -10dB / 2.5:1 압축과 -3dB 피크 제한을 둔다.
  혼자 재생하는 기본 타격은 압축 임계값보다 작으므로 원래 음량을 유지한다.
  정산·경매·HUD 소리는 기존 버스를 사용한다.

`tests/validate_mining_audio.gd`는 실제 범위 피해·공명 전파, 대표음 선택, 재생 간격,
직접 타격 우선권, 잔향 감쇠, 보스의 공용 믹스 사용을 확인한다.

2026-09-14 Godot 4.7.2의 실제 믹스 출력 비교에서는 같은 입력에 대해 단일 타격 RMS가 동일했다.
9개 접촉을 포함하는 범위 공격은 평균 4.65dB, 반복 공명 장면은 17.59dB 낮아졌고,
50ms 간격의 직접 타격 32회는 모두 재생됐다. 이는 비교 시나리오 측정값이며
실제 게임의 감소 폭은 조각 구성과 도구에 따라 달라진다.
