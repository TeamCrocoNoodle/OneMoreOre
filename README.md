# OneMoreOre

Godot 4.7.2 / GDScript로 만든 3D 카툰 채굴 프로토타입.
`project.godot`을 열고 **F5**로 실행합니다. 게임 화면에는 돌, 곡괭이와 채굴 효과만 표시됩니다.

## 플레이

| 입력 | 채굴 | 돌 회전 / 조준 |
| --- | --- | --- |
| 마우스 + 키보드 | 왼쪽 클릭, 누르고 있기, Space | 오른쪽/가운데 버튼 드래그, 휠, WASD 또는 방향키 |
| 터치패드 | 클릭 또는 클릭 유지 | 두 손가락 스크롤, 보조 클릭 드래그 |
| 터치 화면 | 탭 또는 길게 누르기 | 한 손가락 드래그 |
| 컨트롤러 | A / Cross, 오른쪽 트리거, 오른쪽 범퍼 | 왼쪽 스틱·D-pad로 회전, 오른쪽 스틱으로 조준 |

`G`: 빛줄기 확인용 돌 재생성. `R`: 무작위 돌 생성. `F11`: 전체 화면 전환.

돌의 반지름은 4.9로, 첫 프로토타입의 지름 대비 약 1.87배입니다. 바깥부터 100·80·60·42·26·14개, 총 **6겹 322조각**으로 구성됩니다. 일반 조각은 2~4번 타격하면 깨지며, 보석 바로 앞의 마지막 덮개 돌은 **16 HP**입니다. 검은 균열과 떨어지는 파편을 통해 손상을 확인할 수 있습니다.

각 돌에는 **일반 보석 5개와 특별 보석 1개**가 들어갑니다. 낮은 등급부터 **흰색 → 초록색 → 파란색 → 노란색 → 보라색 → 붉은색**을 하나씩 배정했습니다. 일반 보석은 앞의 다섯 등급이며, 특별 보석은 더 큰 붉은 별 결정입니다. 보석은 처음부터 돌 안에 존재하며, 덮개를 깨서 노출한 다음 직접 타격해 꺼냅니다. 한 보석을 꺼내도 다른 돌조각과 보석은 그대로 유지됩니다.

보석의 마지막 덮개를 때릴 때마다 금과 가장자리에서 빛줄기가 뻗어 나옵니다. 첫 타격은 항상 흰색이며, 체력이 줄수록 그 보석의 실제 등급까지 차례로 올라갑니다. 붉은 등급 덮개는 1·4·6·9·11·13번째 타격에 각각 흰색·초록색·파란색·노란색·보라색·붉은색에 도달합니다. 마지막 타격으로 덮개가 떨어지면 보석이 직접 보입니다. 타격 전에는 빛이 없고, 광선은 다른 돌에 가려지며, 보석 회수와 돌 초기화 시 남은 빛도 정리됩니다.

**시작 돌은 빛줄기 확인용 배치**입니다. 앞면에 여섯 등급을 각각 한 조각 뒤에 숨겼습니다. 오른쪽 가운데의 덮개를 길게 누르면 흰색부터 붉은색까지 여섯 색을 모두 볼 수 있습니다. `G`로 이 배치를 다시 만들 수 있습니다. `R` 또는 완전 채굴 후 생성되는 일반 돌에서는 보석의 위치와 깊이가 다시 무작위로 배치됩니다.

무작위 돌은 중앙을 뚫는 것만으로 내용물을 전부 알 수 없습니다. 돌을 돌려 여러 면과 깊이를 탐색하세요. 모든 돌조각을 캐고 여섯 보석을 전부 꺼내면 잠시 뒤 새로운 무작위 돌이 생성됩니다. 누르고 있는 채굴 입력은 다음 돌에서도 이어집니다. 자동 검증에서는 고정 seed로 같은 배치를 재현합니다.

돌·곡괭이·보석·파편은 실행 시 생성하는 원본 3D 메시입니다. 참고 이미지 파일이나 외부 유료 에셋은 포함하지 않습니다. 사운드는 시작할 때 WAV로 합성해 두고 재생합니다. UI, 판매, 업그레이드, 저장 기능은 이 프로토타입 범위에 포함하지 않습니다.

## 검증

Godot 실행 파일을 PATH에 등록한 경우:

```powershell
godot --headless --path . --log-file .godot/integration.log --script res://tests/validate_mining.gd
godot --headless --path . --log-file .godot/gem_light.log --script res://tests/validate_gem_light.gd
godot --path . --log-file .godot/capture.log -- --capture-sequence
```

첫 명령은 실제 물리 raycast와 입력 이벤트로 여섯 층의 채굴, 마지막 덮개 판정, 보석 배치·은폐·노출, 재생성 조건, 남은 빛 정리와 입력 장치별 조작을 확인합니다. 두 번째 명령은 여섯 등급의 체력별 색 전환과 매 타격의 광선, 기존 피해 보존, 깊이 판정을 검증합니다. 세 번째 명령은 실제 곡괭이 타격으로 여섯 빛줄기와 보석 노출·획득을 재생하고 `artifacts/lights_*.png`에 화면을 저장합니다.

Windows / Godot 4.7.2 Compatibility 렌더러에서 실행 및 화면 검증을 수행했습니다. 입력 이벤트 자동 검증은 실제 Android·iOS 기기와 물리 컨트롤러 테스트를 대체하지 않습니다.

## 플랫폼

Windows, macOS, Linux, Android, iOS용 개발 export preset을 제공합니다. 공통 코드는 GDScript와 Compatibility 렌더러를 사용하며, 가로·세로 화면 비율에 맞춰 카메라와 곡괭이 배치를 조정합니다. 파편은 수량 제한이 있는 MultiMesh로 렌더링합니다.

현재 환경에는 Godot 4.7.2 export template과 Android SDK/JDK가 준비되어 있지 않아 플랫폼별 실행 패키지는 생성하지 않았습니다. Godot에서 일치하는 export template을 설치한 다음 `builds/` 아래로 내보낼 수 있습니다. Android는 SDK/JDK, iOS는 macOS의 Xcode 및 Apple 서명 설정이 필요합니다. 배포 전 bundle ID `com.onemoreore.prototype`와 각 플랫폼 서명 설정을 프로젝트에 맞춰 변경하세요.

컨트롤러 입력과 진동 설정의 엔진 동작은 [Godot 공식 문서](https://docs.godotengine.org/en/stable/tutorials/inputs/controllers_gamepads_joysticks.html)를 기준으로 합니다.
