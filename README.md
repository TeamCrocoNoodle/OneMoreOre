# OneMoreOre

Godot 4.7.2 / GDScript로 만든 3D 카툰 채굴 프로토타입.
`project.godot`을 열고 **F5**로 실행합니다. 돌·곡괭이·채굴 효과와 함께 제한 시간, 보석함, 골드 정산 UI가 표시됩니다.

## 기초 밸런스 v1

4시간대 캠페인을 위한 스킬·주 도구·보조 도구·원석·보석·보스 수치를 적용했습니다. 전체 스킬, 황금 곡괭이 한 개 장착, 보조 도구 7종 동시 사용이 최종 구성입니다. 기본 수치 시뮬레이션은 약 4시간 16~25분이며 실제 장시간 플레이 측정은 아닙니다. [밸런스 표·진행 구간·검증 조건](docs/balance/README.md), [노드별 수치 CSV](docs/balance/skills.csv), [전체 수치 JSON](docs/balance/values.json)을 참고하세요.

## 스태미나 채굴과 정산

첫 유효한 채굴 동작부터 **스태미나 300 / 300**이 소모됩니다. 기본 소모는 초당 10으로, 숫자는 약 0.1초마다 1씩 줄고 상단 바는 부드럽게 감소합니다. 기본 채굴 가능 시간은 30초로 유지되며 마지막 5초의 색·소리 경고도 유지됩니다. 창이 비활성화되면 소모와 채굴 입력이 잠시 멈춥니다. HUD·스킬 설명·도구 설명·회복·보스 피해 알림은 같은 표시 단위를 쓰며, 내부 밸런스 값은 [stamina_display.gd](scripts/stamina_display.gd)에서 10배로 환산해 표시합니다.

채굴 화면은 왼쪽 위의 얇은 시간 바, 오른쪽 위의 Gold, 오른쪽 아래의 보석 아이콘과 개수를 중심으로 표시합니다. 정산 화면은 배경을 어둡게 덮고 대표 보석과 획득 Gold를 크게 보여 주며, 옆에서 항목별 수량과 금액을 차례로 계산합니다. 흰색 글자와 따뜻한 금색 강조를 사용하고, 큰 테두리와 겹친 카드 장식을 줄였습니다.

일반 돌 조각은 완전히 부술 때 한 개로 기록합니다. 보석을 품은 조각과 파괴 파편은 일반 돌 개수에 중복 포함하지 않습니다. 보석은 소유 조각을 부순 순간 획득 내역에 기록되고, 실제 결정이 구멍에서 나온 뒤 오른쪽 아래 보석함으로 날아가 도착할 때 해당 등급 숫자가 올라갑니다.

시간이 끝나면 추가 타격을 막고 마지막 보석의 이동을 마친 뒤 정산합니다. 돌 조각부터 획득한 보석의 낮은 등급 순으로 수량×단가를 계산하며, 각 행과 합계가 짧은 효과음에 맞춰 증가합니다. 마지막 골드 금액은 한 번만 지급합니다. `결과 바로 보기`로 연출을 건너뛰어도 지급액은 같습니다. `다시 채굴하기`로 새 라운드를 시작하며, 보유 골드와 구매한 스킬은 실행 중 라운드 사이에 유지됩니다. 아래 표는 업그레이드 전 기본 단가입니다.

| 정산 항목 | 개당 Gold |
| --- | ---: |
| 일반 돌 조각 | 1 |
| 일반 보석 | 15 |
| 특별 보석 | 60 |
| 희귀 보석 | 220 |
| 전설 보석 | 800 |
| 신화 보석 | 2,400 |
| 고대 보석 | 7,200 |
| 이형 보석 (Exotic) | 22,000 |

시간 안에 원석을 전부 캐거나 구매한 분쇄기를 `R`로 사용해도 그 라운드의 남은 시간과 이미 획득한 내역은 유지됩니다. 정산 창은 마우스·터치와 키보드/컨트롤러의 확인 버튼으로 조작할 수 있습니다. 실행 종료 후 저장은 아직 없습니다.

## 원석 진행도

**경매 전 채굴 정산으로 실제 지급받은 누적 Gold와 보스 처치 단계**에 따라 원석이 성장합니다. Gold 조건을 넘겨도 아직 처치하지 않은 보스를 건너뛸 수 없습니다. 보유 잔액과 분리되어 있어 스킬·도구를 구매해도 진행도가 내려가지 않고, 경매의 당첨이나 손실도 원석 단계에 영향을 주지 않습니다. 광물 가치·총수입·황금의 날 같은 채굴 수입 강화는 반영하며, 분쇄한 보석은 할인 후 지급액만 누적합니다. 보스 최초 처치 보상도 정산에 포함합니다. 정산을 확정하기 전에는 Gold 진행도를 올리지 않고, 중복 정산으로 두 번 오르지 않습니다.

| 단계 / 테마 | 누적 채굴 Gold | 반지름 | 층 / 돌 조각 | 기본 보석 수 | 기본 구성의 최고 등급 |
| --- | ---: | ---: | ---: | ---: | --- |
| 풍화 원석 / 회색 돌 | 0 | 2.6 | 3겹 / 74 | 4 | 일반 · 흰색 |
| 이끼 광맥 / 녹색 이끼 무늬 | 6,500 + 첫 보스 | 3.0 | 3겹 / 102 | 7 | 특별 · 초록색 |
| 서리 광맥 / 푸른 서리층 | 45,000 + 두 번째 보스 | 3.5 | 4겹 / 156 | 9 | 희귀 · 파란색 |
| 황철 광맥 / 황금색 광물 입자 | 260,000 + 세 번째 보스 | 4.0 | 4겹 / 210 | 12 | 전설 · 노란색 |
| 흑요 광맥 / 보라색 돌결 | 6,500,000 + 네 번째 보스 | 4.6 | 5겹 / 308 | 16 | 신화 · 보라색 |
| 태고의 화산암 / 붉은 갈색 화산층 | 6,500,000 + 다섯 번째 보스 | 5.2 | 6겹 / 424 | 22 | 고대 · 빨간색 |
| 이형의 광맥 / 검은 돌과 옅은 광물층 | 20,000,000 + 여섯 번째 보스 | 5.8 | 7겹 / 512 | 29 | 이형 · 검정과 파스텔 오팔색 |

경제·체력 수치는 [game_balance.gd](scripts/game_balance.gd), 보석 구성과 테마는 [ore_progression.gd](scripts/ore_progression.gd)에 모았습니다. 마지막 일반 원석은 시작 원석보다 반지름 약 2.23배, 부피 약 11배이며 독립적으로 부술 수 있는 조각이 512개로 늘어납니다. 일반 조각의 기본 체력은 단계별 3·5·8·12·18·24·32, 보석을 품은 조각은 12·20·32·48·72·96·128 HP입니다. 일반 조각은 안쪽 층당 +6%, 일부 조각 +12%의 변동을 적용합니다. 최종 강화는 일반 조각의 체력 성장을 앞서 한 번에 부술 수 있습니다. 테마마다 색·표면 무늬·모서리와 돌출 정도를 바꾸며, 광맥 무늬 자체에는 발광을 넣지 않아 보석 균열 빛과 구별됩니다. 카메라는 원석 전체가 가로·세로 화면 안에 들어오도록 조정합니다.

단계를 올린 정산에서는 새 광맥 이름을 알려주고, 다음에 생성하는 원석부터 적용합니다. 상단 제한 시간 아래에는 현재 광맥과 다음 보스까지의 원석 파괴 수를 표시하며, Gold 조건이 남았으면 필요한 Gold를 표시합니다. 원석별 보석은 **바깥층 아래 여러 깊이의 무작위 조각 안**에 숨깁니다. 기존 광물 수·희귀도 스킬과 함께 작동하며, 아직 해금하지 않은 보석은 희귀도 강화로도 나오지 않습니다. 보석 총수는 단계별 내부 공간에 맞춰 12·16·22·28·36·44·52개로 제한합니다.

큰 원석의 돌·보석·특수 조각 생성은 약 5ms 작업 예산으로 여러 프레임에 나눕니다. 단일 조각을 처리하는 동안에는 예산을 조금 넘길 수 있습니다. 준비 중에는 완성도를 표시하고 제한 시간·채굴·보조 도구 작동을 멈추며, 모두 숨겨 넣은 뒤 채굴을 재개합니다. 생성 중 원석을 교체하면 이전 작업과 충돌체를 정리합니다. 진행도는 다른 구매 내역과 같이 실행 중 라운드 사이에 유지됩니다.

## 보스 원석과 승리

`스크린샷 2026-09-13 164020.png`의 여섯 패턴과 임시 최종 보스를 구현했습니다. 해당 광맥의 누적 원석 파괴 수가 아래 조건에 도달하고, **현재 노동 라운드에서도 원석을 한 개 이상 완전히 파괴**하면 다음 원석 자리에 보스가 등장합니다. 입장하면 최대 체력까지 회복하고, 생성 중에는 시간과 입력을 멈춥니다. 실패해도 누적 파괴 수는 유지하며, 다음 노동 라운드에서 원석을 다시 깨면 재도전합니다. 같은 라운드에서는 한 번만 도전합니다.

| --- | --- | --- | ---: | ---: | --- |
| 1 · 되살아나는 거암 | 뿌리 달린 세로 거암 · 녹회색 채석장 | 조각이 1.6초 뒤 재생, 매번 최대 체력 절반, 최대 두 번 | 18 | 1,500 | 특별 / 이끼 광맥 |
| 2 · 수호석의 성채 | 성채 돌과 보호 문양 · 에메랄드 요새 | 보호석 주변은 피해 면역, 보호석을 부수면 해제 | 24 | 9,000 | 희귀 / 서리 광맥 |

시한핵의 전선은 돌 표면 아래에 있으므로 덮고 있는 조각을 먼저 캐야 자를 수 있습니다. 전선 색과 효과의 대응은 도전마다 섞입니다. 이 보스에서는 일반 시간 소모를 멈추고 60초 폭발 타이머를 사용합니다. 포격수의 남은 돌과 비행 중인 돌이 모두 사라지면 승리합니다. 약점 다섯 개를 깨거나 해체에 성공하는 경우에는 남은 돌을 즉시 정리합니다.

보스전에는 **원석 분야 스킬 효과**를 잠시 비활성화합니다. 체력·공격·Gold 분야와 장착 도구는 유지합니다. 분쇄기는 보스를 건너뛸 수 없고, 레이저·쐐기·기폭장치의 피해도 보호·면역·휴식 규칙을 따릅니다. 보스 처치 보상은 별도 정산 행으로 한 번만 지급하며 스킬 수입 배율로 증폭하지 않습니다. 정산 완료 후 업그레이드 창으로 이동합니다. 마지막 보스는 승리 정산을 마친 뒤 다음 채굴·업그레이드·경매를 열지 않습니다.

첫 보스 전에는 **흰색 일반 보석 네 개**만 들어 있습니다. 처치 순서에 따라 초록 → 파랑 → 노랑 → 보라 → 빨강 → 이형을 해금합니다. 이형은 제공된 색상 레퍼런스처럼 어두운 면과 흰색·분홍·민트·라일락 빛이 함께 보이는 결정이며, 보석·균열 빛·실제 모델의 보석함 이동·정산 단가까지 연결했습니다. 보스 모델과 무대는 코드로 직접 만든 3D 메시이고, 보스별 등장·타격·파괴·능력·승리음 **35개**도 녹음 없이 새로 합성했습니다. [음원 설명](assets/audio/bosses/README.md).

등장 조건·보상·체력은 [game_balance.gd](scripts/game_balance.gd)에 모은 기초 밸런스입니다. 조각당 HP는 14·28·90·150·260·240·1,400이며 첫 보스는 14→7→3.5로 재생합니다. 패턴 시간은 [boss_runtime.gd](scripts/boss_runtime.gd)에 있습니다. 진행·해금은 기존과 같이 실행 중 유지하며 종료 후 저장은 아직 없습니다.

```powershell
godot --headless --path . --script res://tests/validate_bosses.gd
godot --path . --script res://tests/capture_bosses.gd
```

보스 검증은 실제 일반 원석 파괴에서 등장·회복·처치·정산·업그레이드·다음 광맥까지 이어지는 흐름, 일곱 희귀도 상한, 이형 균열 빛과 UI 도착, 여섯 패턴, 투사체 요격 충돌, 최종 승리, 35개 PCM 규격을 검사합니다. `artifacts/boss_*.png`와 `boss_capture_report.json`은 모델·패턴·가로/세로 UI 확인용입니다. 캡처에서는 보스 진입 조건과 Gold를 직접 주입하며, 실제 플레이로 획득한 진행도가 아닙니다.

## 경매

Gold 정산이 끝나면 `경매`에서 이번 정산 금액 전액을 걸고 **한 번** 참여할 수 있습니다. 참여하지 않고 바로 다음 채굴을 시작해도 됩니다. 미리보기에는 가능한 조정률과 최종 금액을 보여 주며, `경매 시작`을 누를 때만 결과를 추첨합니다. 시작 전 돌아가기는 금액과 난수를 바꾸지 않습니다.

| 조정 | 받는 금액 | 기본 추첨 비중 |
| --- | ---: | ---: |
| -100% | 0배 | 23% |
| -50% | 0.5배 | 25% |
| +50% | 1.5배 | 25% |
| +100% | 2배 | 25% |
| +200% | 3배 | 2% |

위 확률은 개발용 기록이며 게임 UI에는 표시하지 않습니다. 전액 손실 다음 경매는 전액 손실을 제외하고 **25:25:25:2** 비율로 추첨하므로, 보호가 적용된 추첨의 조건부 확률과 전체 플레이의 누적 빈도는 기본 비중과 달라집니다. 보호 이력은 실행 중 다음 라운드·경매를 건너뛴 라운드에도 유지됩니다. 정산 101G의 결과는 각각 0·50·151·202·303G이며, 소수 Gold는 최종 금액에서 내립니다.

입찰 금액이 빠르게 바뀌다가 감속해 결과에 멈추고, 최종 금액을 올리거나 내립니다. 양의 결과에는 3D 동전이 퍼지며, +200%는 더 큰 금색 빛과 별도 낙찰음으로 강조합니다. 시작 망치·입찰 클릭·손실·낙찰·최고가 낙찰 효과음은 배경 음악 없이 합성한 PCM을 재사용합니다. `결과 바로 보기`는 이미 정해진 결과의 연출만 건너뜁니다.

기본 정산은 먼저 지급하고, 경매에서는 그 정산 금액의 차액만 한 번 반영합니다. 이전에 모은 Gold를 통째로 배팅하지 않습니다. 업그레이드로 지갑 잔액을 정산 원금보다 적게 쓴 경우에는 해당 경매에 참여할 수 없습니다. 입찰 중 재추첨·다음 라운드·업그레이드는 막고, 결과를 확인한 뒤 정산 창으로 돌아가 이어서 진행합니다. 마우스·터치·키보드·컨트롤러로 조작할 수 있습니다.

## 스킬 트리

채굴 시작 전이나 정산이 끝난 뒤, 왼쪽 아래 `업그레이드` 버튼 또는 `U`로 엽니다. 컨트롤러에서는 `Y / Triangle`을 사용합니다. 제공된 `image.png`, `image1.png`, `image3.png`, `image4.png`의 강화 요소와 연결을 옮긴 **138개 노드·143개 연결**입니다. 모든 노드는 정수 격자에 놓이며, 체력은 왼쪽 위, 공격은 왼쪽 아래, Gold는 오른쪽 아래, 원석은 오른쪽 위로 뻗습니다. 찬란함과 희귀 광물 가지도 서로 연결됩니다. 시작 공격력 +1 노드는 이미 습득한 상태이고, 처음에는 이 노드와 이웃 네 개만 보입니다. 구매하면 그 이웃이 추가로 드러나며, 연결된 이웃 중 하나를 습득하면 구매할 수 있습니다.

기존 HUD의 어두운 바탕·흰색 그림·금색 강조를 유지하고, 분야는 노드 가장자리의 작은 색 표시로 구분합니다. 그림의 화살표·주사위·시계·십자·동전으로 피해량, 확률, 유지 시간, 회복, 수입 강화를 구별합니다. 마우스를 올리면 위에는 동전과 가격, 아래에는 이름과 상세 효과가 나옵니다. 클릭 후 나타나는 체크 버튼을 눌러야 Gold를 지불하고, 다른 곳을 누르면 취소합니다. 터치·키보드·컨트롤러도 같은 확인 절차를 사용합니다. 드래그로 이동하고 휠·핀치 또는 `− / +`로 확대·축소하며, `⌂`는 현재 공개된 노드 전체를 보여 줍니다. 축소 화면에서 노드를 누르면 자세히 볼 수 있는 크기로 확대됩니다.

효과는 [skill_balance.gd](scripts/skill_balance.gd), 가격 곡선은 [game_balance.gd](scripts/game_balance.gd)에 모았습니다. 공격력 +0.8, 속도 +16%, 범위 +25%, 최대 스태미나 +40, 총수입 +12%, 광물 가치 +20%입니다. 첫 이웃은 60G이며 연결 깊이와 고유 효과별 가중치로 가격을 올립니다. 전체 유료 노드 137개의 합계는 16,609,720G입니다. 같은 항목의 확률 강화는 가산합니다. 회복 돌조각의 마지막 강화는 회복량 +25%입니다.

기본 스태미나 300을 초당 10씩 소모하므로 첫 채굴은 30초입니다. 일반 회복은 한 라운드에서 최대 스태미나의 80%까지 누적되며, 부활·보스 입장 회복은 별도입니다. 최대 강화와 맥주는 스태미나 520·소모 8.2/초·25% 부활 2회이고, 무한히 회복해도 일반 라운드는 약 145.9초 안에 정산합니다. 소모 감소는 최대 표시 수치를 늘리지 않고 감소 속도를 늦춥니다. 부활 횟수와 콤보·추가타격·광물 강화는 새 라운드에서 초기화합니다. 원석만 교체할 때는 스태미나와 라운드 진행을 유지합니다. 콤보는 돌조각 10개마다 +1, 기본 스택당 공격력 +1%이고, 파괴로 유지 시간을 갱신합니다. 추가타격은 5번째 기본 공격에서 확률로 충전되며, 충전된 다음 공격들의 속도가 200%가 됩니다. 조건을 만족한 연속 치명타도 이 충전 공격에 적용됩니다.

시작 원석은 일반 네 개를 안쪽 두 층에 숨기며, 이후에는 누적 Gold와 보스 해금에 따른 광맥 구성을 사용합니다. 광물 등장 강화는 비어 있는 내부 조각마다 추가 보석 확률을 올리고, 희귀도 강화는 해금한 범위 안에서 상위 보석을 얻을 기회를 줍니다. 기존 희귀도 스킬의 원본 추첨 비중은 희귀 76%, 전설 18%, 신화 5%, 고대 1%이며, 추첨 결과는 현재 해금 상한으로 제한합니다. 이형은 여섯 번째 보스 이후 광맥의 보장 구성과 추가 광물 추첨에 포함됩니다. 찬란한 보석은 등급을 유지하면서 결정이 밝아지고 정산 가치가 증가합니다. 공명 돌은 타격 시 인접 피해, 회복 돌은 파괴 시 체력, 폭탄 돌은 인접 폭발 피해, 황금 돌은 Gold를 줍니다. 각 돌은 색과 표면 문양으로 구분됩니다.

직접 범위 타격은 파괴 전에 보이던 조각을 대상으로 잡습니다. 공명·폭탄·충격파의 연쇄 피해는 동일한 출발 돌에서 한 번만 전파하고, 한 공격 최대 96건·한 물리 프레임 최대 3건으로 나눠 처리합니다. 연쇄 피해가 치명타·처형·충격파를 다시 추첨하지 않습니다. 새 원석이나 라운드 종료 시 대기 중인 연쇄 피해를 정리합니다.

Gold 드롭·황금 돌·광물 획득 보너스는 채굴 중 표시하고 정산에 합산합니다. 찬란함 추가 가치는 해당 보석 행에 포함하고, `(돌 + 보석 + 추가 Gold) × 총수입 배율` 다음 황금의 날 2배를 적용합니다. 보너스 행까지 합한 금액만 한 번 지급하며, 이후 경매의 원금에도 반영됩니다. 황금의 날 추첨은 정산당 한 번이고, 누적 확률은 당첨 시 초기화됩니다. 정산 후 구매는 다음 라운드부터, 아직 캐지 않은 시작 원석의 원석·찬란함 관련 구매는 즉시 새 원석 구성에 반영됩니다.

## 도구 진열대

업그레이드 창의 상단에서 **스킬 트리 / 도구** 탭을 전환합니다. 선택한 탭은 밝은 글자와 금색 밑줄로 표시하고, 지갑과 닫기 버튼은 두 탭이 공유합니다. 마우스·터치뿐 아니라 `Q / E`, 컨트롤러 `LB / RB`로도 전환할 수 있습니다. 스킬 구매를 확인하기 전에 다른 탭으로 이동하면 그 선택은 취소되고 Gold는 차감되지 않습니다.

도구 탭 안에서 **주 도구 / 보조 도구**를 전환합니다. 실제 3D 철제 진열대에는 주 도구 6종 또는 보조 도구 7종이 놓입니다. 굵은 중앙 기둥으로 나뉜 좌우 두 칸·3~4단 선반·깊은 측판·철판 뒤벽·육각 볼트·금속 가격 명판을 사용합니다. 정면에서 조금 내려다보는 원근 카메라와 조명을 도구·진열대가 공유하고, 명판 글자와 클릭 영역도 실제 모델의 투영 위치를 따라갑니다. 좁은 화면에서도 좌우 칸을 유지하며, 높이가 부족하면 휠·터치패드·터치 드래그로 스크롤합니다.

임시 색상 변형을 제거하고 **곡괭이 → 도끼 → 망치 → 착암기 → 드릴 → 황금 곡괭이**로 교체했습니다. 도구를 누르면 실제 모델·능력·가격이 나오고, `✓`로 구매를 확정합니다. 주 도구는 구매 즉시 장착하며, 보유 도구는 무료 재장착합니다. 보조 도구는 한 번 구매하면 소유한 것이 모두 함께 작동합니다. 바깥 클릭·탭 전환은 취소, `Esc / B`는 상세 창부터 닫습니다. Gold가 부족하면 확정 버튼이 비활성화됩니다. 구매·장착은 채굴 시작 전 또는 정산 완료 후에 가능하며, 소유·장착 상태는 다음 라운드에도 유지됩니다.

분쇄기·기폭장치는 터치/마우스용 화면 버튼으로도 사용합니다. 기폭장치를 소유하면 Space는 폭파 전용이 됩니다. 맥주는 소모하지 않으며 첫 채굴 스태미나가 300에서 360으로 늘어납니다. 탐지기는 공격 범위와 관계없이 정확한 조준점을 기준으로 측정하고, 돌을 조준하지 않을 때는 신호를 숨깁니다. 엑스레이는 등급이나 위치를 알려주지 않습니다. 레이저는 대기·업그레이드·포커스 이탈 중 시간을 누적하지 않습니다.

분쇄 전에 모은 보석은 제값을 유지합니다. 남아 있던 보석은 광물 가치 스킬과 찬란함을 반영한 뒤 절반으로 계산하고, 정산 행에 `분쇄 −n G`를 표시합니다(소수는 가장 가까운 정수). 갈아버린 일반 돌에서는 판매 Gold나 돌 파괴 보너스를 얻지 않습니다. 기폭장치와 정은 일반 파괴처럼 돌·보석을 정산합니다. 보조 도구로 얻은 실제 보석도 보석함으로 이동해 카운트됩니다. 분쇄·폭파 후 다음 원석으로 넘어가도 남은 시간·분쇄 대기시간·사용한 폭파 횟수는 유지되며, 시간 종료 후의 자동 원석 교체는 취소됩니다.

[aux_tool_visual.gd](scripts/aux_tool_visual.gd)에서 포탑·거품 잔·안테나 탐지기·톱니 분쇄기·스캔 모니터·금속 쐐기·기폭 상자를 직접 모델링했습니다. 진열대·상세 창·채굴 장면·HUD에서 같은 입체 메시를 공유합니다. [전용 효과음 18개](assets/audio/auxiliary/README.md)도 녹음 없이 새로 합성했습니다. 보조 도구 HUD는 한 번 렌더한 모델 아틀라스를 공유하고, 전체 분쇄는 최대 10개의 기존 메시와 고정된 파티클 묶음을 사용하므로 74조각의 파편 메시를 한 프레임에 새로 만들지 않습니다.

검증: `--headless --script res://tests/validate_aux_tools.gd`. 렌더링 검토: `--script res://tests/capture_aux_tools.gd` (20,000,000G를 검토용으로 주입하고 실제 구매). 결과는 `artifacts/aux_tools_*.png`와 `aux_tools_report.json`에 저장합니다.

## 플레이

주 도구는 마우스 커서(컨트롤러·터치에서는 조준 위치)를 계속 따라갑니다. 누르면 커서 근처에서 휘두르거나 기계를 작동하며, 공격 중 커서를 옮겨도 현재 위치를 따라가 그곳을 타격합니다. 타격 후에도 현재 커서 옆에서 자세를 회복합니다.

도구는 원석 안쪽을 향해 상하좌우로 돌아갑니다. 원석 좌우 양끝에서는 서로 반대쪽 넓은 면이 보이고, 중앙에서는 날의 얇은 옆면이 보이며 화면 안쪽으로 타격합니다. 위아래 기울기는 최대 65도로 제한하며, 대각선에서는 좌우 회전과 결합됩니다. 회전 폭은 실제 원석 크기와 카메라에 맞춰 조정됩니다. 손잡이 축과 날 끝의 커서 접촉, 잔상 궤적에도 같은 회전을 적용합니다.

| 입력 | 채굴 | 돌 회전 / 조준 |
| --- | --- | --- |
| 마우스 + 키보드 | 왼쪽 클릭, 누르고 있기, Space(기폭장치 구매 전) | 오른쪽/가운데 버튼 드래그, 휠, WASD 또는 방향키 |
| 터치패드 | 클릭 또는 클릭 유지 | 두 손가락 스크롤, 보조 클릭 드래그 |
| 터치 화면 | 탭 또는 길게 누르기 | 한 손가락 드래그 |
| 컨트롤러 | A / Cross, 오른쪽 트리거, 오른쪽 범퍼 | 왼쪽 스틱·D-pad로 회전, 오른쪽 스틱으로 조준 |

`R`: 구매한 분쇄기 사용. `Space`: 구매한 기폭장치 사용. `F11`: 전체 화면 전환. 시간 제한 없이 채굴을 확인하려면 `-- --mining-sandbox`로 실행합니다. 이 확인 모드에서는 `R`로 원석을 자유롭게 초기화하고 `G`로 여섯 등급 확인용 돌을 생성할 수 있습니다.

기본 원석의 반지름은 **2.6**이며, 바깥부터 38·24·12개, 총 **3겹 74조각**으로 구성됩니다. 이전 확인용 원석(반지름 4.9, 322조각)보다 작게 줄였고, 화면에서도 작은 크기로 보이도록 카메라와 바닥 그림자를 맞췄습니다. 일반 조각은 2~4번 타격하면 깨지며, 보석을 품은 조각은 **16 HP**입니다. 검은 균열과 떨어지는 파편을 통해 손상을 확인할 수 있습니다.

처음 등장하는 기본 원석에는 **일반 보석 네 개**가 들어갑니다. 보스 처치 전에는 상위 등급이 나오지 않으며, 광물 등장 강화로 보석 수를 늘릴 수 있습니다. 보석의 희귀도와 최종 균열 빛 색은 다음과 같습니다.

| 희귀도 | 보석·빛 색 |
| --- | --- |
| 일반 | 흰색 |
| 특별 | 초록색 |
| 희귀 | 파란색 |
| 전설 | 노란색 |
| 신화 | 보라색 |
| 고대 | 빨간색 |
| 이형 (Exotic) | 검정과 흰색·분홍·민트·라일락이 어우러진 오팔색 |

보석 모양의 변형은 희귀도와 별개이므로, 서로 다른 모양의 일반 보석도 모두 흰색입니다. 보석은 참고 이미지처럼 위쪽이 좁고 아래쪽이 두툼한 비대칭 입체로, 넓은 절단면과 얇게 다듬은 모서리가 있습니다. 돌과 같은 단계별 명암에 색이 짙은 내부 면과 시점에 따라 움직이는 반사를 더했습니다. 내부의 광학적 깊이는 불투명 셰이더로 표현하므로 배경이나 다른 돌이 보석을 뚫고 비치지 않습니다.

보석은 바깥층 아래 두 깊이에 나눠 숨깁니다. 기본 구성은 각 깊이에 두 개씩이며, 깊이에 배정하는 희귀도와 실제 조각은 무작위로 고릅니다. 서로 다른 조각을 쓰고 방향도 떨어뜨려 배치합니다. 특별 보석의 위치나 깊이는 고정되지 않습니다. 보석마다 이를 품은 돌조각의 실제 내부 공간에 맞춰 넣으므로, 주변 조각을 제거하거나 돌을 돌려도 주인 조각을 부수기 전에는 보석이 보이거나 채굴되지 않습니다.

보석을 품은 조각의 체력이 0이 되면 **그 타격에서 보석을 즉시 자동 획득**합니다. 추가 클릭이나 보석 타격은 필요하지 않습니다. 획득음과 반짝임이 재생되고, 보석은 방금 깬 구멍에서 튀어나와 넓은 절단면을 보여 준 뒤 오른쪽 아래 보석함으로 날아갑니다. 이 연출 중에는 이미 획득된 상태이며 채굴 입력을 가로막지 않습니다. 다른 돌조각과 그 안의 보석은 그대로 유지됩니다. 시간 제한 없는 확인 모드에서는 기존의 상승·사라짐 연출을 사용합니다.

돌조각에는 큰 균열 묶음이 최대 두 개 생기며, 각 묶음은 세 갈래로 뻗습니다. 이후 타격은 가장 가까운 기존 금에 짧게 연결하고, 이미 금이 간 곳은 그 금을 깊게 만듭니다. 길이와 두께의 성장을 제한해 여러 번 때려도 돌 표면을 잔금으로 뒤덮지 않도록 했습니다. 보석을 품은 조각에서는 실제로 열린 균열을 따라 빛이 새며, 새로 때린 부위와 균열의 방향에 맞춰 빛줄기도 달라집니다. 보석을 담지 않은 주변 조각은 빛을 내지 않습니다. 돌의 회전과 타격 시 흔들림에도 균열과 빛이 함께 움직입니다.

균열은 굵은 두 갈래와 작은 곁가지를 가진 각진 경로로 자랍니다. 폭은 꺾임마다 불규칙하게 달라지고, 마지막 끝에서는 뾰족하게 좁아집니다. 양쪽 단면의 명암과 가운데의 어두운 틈으로 깊이를 표현합니다. 갈림길과 교차점에서는 균열의 윤곽을 합친 뒤 노출된 가장자리에만 단면을 만들어, 한 갈래의 벽이 다른 틈을 가로막지 않게 했습니다. 모서리 위치와 색도 이웃 단면끼리 공유해 연결하며, 균열이 둘러싼 돌 부분은 그대로 남습니다. 빛의 중심과 주변 번짐도 같은 폭과 가장자리를 사용하며, 파편은 이 균열의 경로를 따라 나뉩니다.

앞면뿐 아니라 경사진 모서리·옆면·뒷면도 실제 타격 위치에 금이 생깁니다. 길이와 폭은 기존 앞면 균열의 크기를 유지하며, 타격 위치에서 충분히 자란 금만 가까운 모서리를 넘어갑니다. 균열은 실제 메시의 이웃 면을 따라 꺾여 자라며, 모서리를 넘어갈 때 양쪽 면이 같은 경계를 공유합니다. 면에 붙은 균열을 실제 삼각형으로 잘라 돌 밖으로 떠다니지 않게 하고, 면의 경계에는 균열을 가로막는 단면을 만들지 않습니다. 꺾임의 안쪽 벽은 합쳐진 틈 안에서 연결하고, 양쪽 면이 만나는 곳도 같은 안쪽 끝점을 사용해 벽의 폭이 갑자기 사라지지 않게 했습니다. 이미 생긴 꺾임은 움직이지 않고 끝부분만 자랍니다. 조각의 연결 정보는 생성 시 저장하고 균열 메시 갱신은 타격 시에만 수행합니다.

빛줄기는 문틈에서 새어 나오는 빛처럼, 돌 안의 공통 광원에서 모든 실제 균열 선분을 통과해 넓은 빛띠로 펼쳐집니다. 밑변 양 끝은 금의 양 끝에 붙고, 연결된 균열은 멀리 뻗은 끝에서도 이어집니다. 보석의 수납 위치에 광원을 유지해 앞·옆·뒤 각 면의 바깥쪽으로 빛이 나가며, 공통 투영 배율에 제한을 두어 얕은 조각에서도 지나치게 벌어지지 않게 합니다. 균열 가까이는 밝고 멀어질수록 투명해지며, 곧은 경계도 먼 끝에서 살짝 부드러워집니다. 빛띠 사이의 어두운 간격을 남기고 균열 수에 따라 밝기를 조절해 돌 표면이 비쳐 보입니다. 좁은 틈 주변의 빛 번짐과 작은 마름모 반짝임이 이를 받쳐 줍니다.

체력이 0이 되면 누적된 균열을 경계로 돌조각이 여러 입체 파편으로 갈라집니다. 끊긴 균열 끝은 파괴 순간 가장자리까지 이어집니다. 파편의 앞면은 금 모양을 따르고, 두께는 각 파편의 폭과 면적에 맞춥니다. 뒤쪽은 비대칭으로 좁아지고 단면은 비스듬히 꺾여, 얇은 돌 부스러기와 두툼한 쐐기 모양이 섞여 나옵니다. 파편마다 다른 방향과 속도로 벌어져 회전하며 떨어지고, 새 단면은 밝은 돌 색으로 표시합니다. 파편 수와 수명에 제한을 두며, 돌을 초기화하면 남은 파편도 정리됩니다.

첫 타격의 빛은 항상 흰색이며, 체력이 줄수록 그 보석의 실제 등급까지 차례로 올라갑니다. 16 HP·공격력 1의 전시용 붉은 보석 조각은 1·4·6·9·11·13번째 타격에 각각 흰색·초록색·파란색·노란색·보라색·붉은색에 도달합니다. 타격 전에는 빛이 없고, 광선은 다른 돌에 가려집니다. 조각이 파괴되는 순간 균열 빛은 잔상 없이 즉시 사라지며, 돌 초기화 시 남은 빛과 획득 연출도 모두 정리됩니다.

**시작 시에는 작은 원석과 숨겨진 무작위 배치**를 사용합니다. 구매한 분쇄기 사용 또는 완전 채굴 후에는 현재 진행도에 맞는 새 무작위 원석이 생성됩니다. 여섯 등급 확인용 큰 원석은 시간 제한 없는 확인 모드의 `G` 또는 `--capture-sequence`로 요청합니다. 이 확인용 배치에서는 앞면 여섯 조각 안에 등급별 보석을 하나씩 넣어 둡니다. 테스트는 `showcase_on_start = true`를 설정해 이 배치를 명시적으로 선택하거나 `round_enabled = false`로 채굴 동작만 검증할 수 있습니다.

무작위 돌은 중앙을 뚫는 것만으로 내용물을 전부 알 수 없습니다. 돌을 돌려 여러 면과 깊이를 탐색하세요. 모든 돌조각을 캐고 안에 든 보석을 전부 꺼내면 잠시 뒤 새로운 무작위 돌이 생성됩니다. 누르고 있는 채굴 입력은 다음 돌에서도 이어집니다. 자동 검증에서는 고정 seed로 같은 배치를 재현합니다.

돌·주 도구·보석·파편은 실행 시 생성하는 원본 3D 메시입니다. 참고 이미지 파일이나 외부 유료 에셋은 포함하지 않습니다. 주 도구에는 [직접 합성한 전용 WAV 42개](assets/audio/tools/README.md)를 적용했습니다. 도구마다 일반 돌 타격 3개·보석 돌 타격 2개·파괴 1개·스윙/기계 작동 1개가 있습니다. 원본 녹음을 섞지 않고 진동자와 감쇠 공진으로 만든 48 kHz 스테레오 PCM 16-bit이며, Godot 임포트도 무압축입니다. 보석 발견은 이전에 [직접 합성한 발견음](assets/audio/README.md)을 공유합니다. 돌 재생성과 보석함 도착·카운트다운·정산 효과음은 시작할 때 합성해 재사용합니다. 보상 효과음은 배경 음악 없이 짧은 종소리와 코인 소리로 구성한 24 kHz 모노 PCM 16-bit이며, 타격 중에는 오디오를 합성하거나 새 재생 노드를 만들지 않습니다.

## 플랫폼

Windows, macOS, Linux, Android, iOS용 개발 export preset을 제공합니다. 공통 코드는 GDScript와 Compatibility 렌더러를 사용하며, 가로·세로 화면 비율에 맞춰 카메라와 곡괭이 배치를 조정합니다. 작은 돌가루와 반짝임은 MultiMesh로, 균열을 따라 갈라진 큰 파편은 개별 메시로 렌더링하며 각각 수량을 제한합니다.

현재 환경에는 Godot 4.7.2 export template과 Android SDK/JDK가 준비되어 있지 않아 플랫폼별 실행 패키지는 생성하지 않았습니다. Godot에서 일치하는 export template을 설치한 다음 `builds/` 아래로 내보낼 수 있습니다. Android는 SDK/JDK, iOS는 macOS의 Xcode 및 Apple 서명 설정이 필요합니다. 배포 전 bundle ID `com.onemoreore.prototype`와 각 플랫폼 서명 설정을 프로젝트에 맞춰 변경하세요.

컨트롤러 입력과 진동 설정의 엔진 동작은 [Godot 공식 문서](https://docs.godotengine.org/en/stable/tutorials/inputs/controllers_gamepads_joysticks.html)를 기준으로 합니다.
